DevDocs MCP Server

Your DevDocs MCP server is up and running. This server provides web development documentation tools for AI assistants using the Model Context Protocol (MCP).

Connection Information

Connect to the MCP server at: /sse

Available Tools

  • searchDocs: Search for documentation across technologies
  • getDocForTopic: Get detailed documentation for a specific topic
  • listTechnologies: List all available documentation categories
  • getExamples: Get code examples for a specific topic

Using with Claude

To connect Claude Desktop to this MCP server, use the mcp-remote proxy:

npx mcp-remote https://your-worker-domain.workers.dev/sse

Using with Cursor

In Cursor, create an MCP server entry with:

  • Type: command
  • Command: npx mcp-remote https://your-worker-domain.workers.dev/sse
